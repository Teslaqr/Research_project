# Running on Kaggle

This folder contains everything needed to run [SAA+](https://github.com/caoyunkang/Segment-Any-Anomaly)
on the `bottle` category of MVTec-AD, on Kaggle's free GPU.

## Files

- `saa_bottle_demo.ipynb` — the notebook that actually runs (generated by `generate_notebook.py` — edit that script, not the notebook JSON, then regenerate).
- `kernel-metadata.json` — config for pushing this notebook to Kaggle via the CLI.
- `generate_notebook.py` — regenerate the notebook after editing cells: `python kaggle/generate_notebook.py`.

## Option 1: Push via Kaggle CLI (from your laptop)

1. Install the CLI: `pip install kaggle`
2. Put your API token at `~/.kaggle/kaggle.json` (or `~/.kaggle/access_token` for the newer bearer-token style), from kaggle.com → Settings → API.
3. Edit `kernel-metadata.json`: replace `YOUR_KAGGLE_USERNAME` with your actual Kaggle username.
4. From the repo root:
   ```bash
   kaggle kernels push -p kaggle/
   ```
5. Check status / pull logs:
   ```bash
   kaggle kernels status YOUR_KAGGLE_USERNAME/saa-bottle-demo
   kaggle kernels output YOUR_KAGGLE_USERNAME/saa-bottle-demo -p ./kaggle_output
   ```
6. If it fails, copy the error from the log (or the downloaded output folder) back into the chat with Claude, who will fix the notebook/script and you re-push.

## Option 2: Paste into the Kaggle website UI

1. Go to kaggle.com → **Create → New Notebook**.
2. In the right sidebar: **Accelerator → GPU T4 x2**, **Internet → On**, **Add Input → search "mvtec-ad" → add `ipythonx/mvtec-ad`** (or another MVTec-AD dataset you've uploaded).
3. Open `saa_bottle_demo.ipynb` here, copy each cell's content in order into the Kaggle notebook, and run cells top to bottom.
4. On an error, copy the cell's error output back into the chat.

## Notes

- First run downloads ~3GB of model weights — expect the first pass to take a while.
- GPU quota is shared weekly (~30 GPU-hrs on free tier) — close/stop the session when done.
